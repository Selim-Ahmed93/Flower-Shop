# 🌸 Flower Shop Website (Practice Project)

This is a simple and responsive flower shop website created as a practice project using only HTML and CSS. The goal of this project is to improve layout design skills, understand CSS styling, and create a visually appealing user interface.

---

## 🌼 Features

- 🛒 Clean and modern landing page design  
- 📦 Flower product sections  
- 🖼️ Banner with heading and call-to-action  
- 📱 Responsive layout for mobile and desktop  
- 🎨 Pure HTML and CSS (no JavaScript)
